# Idea Planet · SaaS 化 UI 方向

更新时间：2026-09-06

## 核心原则

Planet 是用户安静地看见自己想法的地方，不应该被余额、升级提示和成本信息占满。商业化 UI 应该存在，但只在用户准备调用 AI 或管理账户时出现。

### 主空间保持安静

- 左侧继续只放 Planet、Timeline、Boards 和未来的 Ask Planet。
- Idea 卡片不显示 credits、价格或套餐标签。
- 首页的主要 CTA 是“把一个 Idea 带进来”或“从 Planet 开始一次工作”，不是 Upgrade。
- 只有在真正触发 AI 任务时，才显示预计消耗和剩余余额。

### 账户区承载商业化

云端版本的侧栏底部可以从当前的 `local / private` 迁移为一个账户入口：

```text
┌────────────────────────────┐
│ ✦  idea planet              │
│                            │
│ Planet                     │
│ Timeline                   │
│ Boards                     │
│ Ask Planet                 │
│                            │
│                            │
│ ────────────────────────── │
│  ●  Plus                   │
│  2,840 / 5,000 AI credits  │
│  Manage plan  ·  Settings  │
└────────────────────────────┘
```

这个区域应是低对比度、可折叠的，不与 Idea 内容竞争注意力。Free 用户显示“Try AI · 240 credits left”，但不在每个页面强迫升级。

## 建议的云端导航

当前本地 MVP 的 Planet / Timeline / All ideas 可以保留。接入 Agent 后，新增入口建议是：

- **Ask Planet**：询问、召回、连接自己的 Idea。
- **Boards**：围绕一个主题或项目查看 Idea，不把 Board 变成传统文件夹。
- **Outputs**（后续）：查看由 Planet 产生的草稿、决定和行动结果。

“Agents”不建议单独成为第一层导航。用户应先说清楚自己要完成什么，系统再选择或推荐合适的工作方式。

## Ask Planet 的任务启动界面

不要从一个空白聊天框开始。首屏应提供任务结果入口：

```text
今天想让过去的想法帮你做什么？

[ 写一段文字 ] [ 做一个判断 ] [ 推进一个行动 ] [ 找相关 Idea ]

________________________________________
例如：我准备写一篇关于 AI 产品审美的文章，先找出我过去反复提到的观点

预计消耗 30–60 credits                    [开始]
```

用户选择结果类型后，再展开上下文范围、时间范围、Board 和输出格式。这样 credits 与“任务结果”绑定，而不是与“聊天轮数”绑定。

## AI 任务中的 credits 反馈

### 开始前

在主按钮附近显示：

```text
预计消耗 40 credits · 余额 2,840
```

如果预测不确定，显示范围；如果余额不足，提供轻量模型或缩小范围的选项。

### 执行中

只显示任务进度和阶段，不做跳动的 token 计数：

```text
正在找出与你当前主题最相关的 12 个 Idea
正在比较其中 3 组观点
```

### 完成后

结果旁显示一个可展开的低干扰信息：

```text
本次使用 37 credits · 已保存到 Planet
```

输出本身可以一键保存为新的 Idea，并自动保留来源任务和引用的 Idea。

## Billing / Usage 页面

账单页不应只有支付按钮，应该回答三个问题：我有什么、还剩多少、为什么用了这么多。

```text
Plan: Plus                                      [管理套餐]
本月 AI credits                                  2,840 / 5,000
重置时间                                         12 天后

使用情况
Recall from Planet        18 次                  420 credits
Draft with your Planet     6 次                  890 credits
Research                   2 次                  1,130 credits
其他                                            400 credits

[购买补充 credits]      [查看完整使用记录]
```

存储放在同一页但分开呈现：

```text
附件存储 1.4 GB / 10 GB · 文本 Idea 不计入此限制
```

不要把 `1,400 MB` 和 `2,840 credits` 合并成一个“总额度”。

## 与当前 UI 的衔接

当前界面的纸张、留白、时间线和轻量图标方向可以保留。下一轮改动建议按这个顺序：

1. 先把底部 `local / private` 抽象成未来可替换的账户区，但本地模式仍明确显示 `local / private`。
2. 在不接真实 AI 的情况下，先做 Ask Planet 的本地 Recall 入口，明确标注不调用外部模型，不伪造写作或研究结果。
3. 加入独立的 Usage / Billing 页面原型，使用静态示例数据或空状态，不把假余额写入用户数据。
4. AI 能力接入后，再在任务启动和完成状态中接入真实 credits。

这样既不会破坏当前 Planet 的安静体验，也为云端、订阅和 credits 留出明确位置。
