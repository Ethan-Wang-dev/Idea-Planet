# 当前产品决定

更新：2026-09-07

Idea Planet 是开源、本地优先、用户自持数据的个人工作台。

- 网页是主要工作入口，启动即用。
- 不保留注册、登录、会话、多租户、云端同步或订阅计费系统。
- 个人内容和任务保存在用户机器的 SQLite 中；浏览器缓存用于离线待写入。
- 用户将自行配置模型 Provider 和 API Key，该功能仍待实现。
- 产品核心仍是让过去的 Idea 参与今天的创作、判断和行动。
- 暂不接 Codex、Claude Code 或 MCP；发布时再整理让代码 Agent 自动本地部署的说明。

域名、Cloudflare 可以继续作为项目入口。Zeabur 仅是未来隔离 Demo 的候选，不将当前无账户的个人工作台直接作为公共多人服务。

早期闭源 SaaS 方案已放弃，旧代码可从 Git 历史恢复；旧个人数据库文件不自动删除。
