# 本地工作台开发路线

更新：2026-09-07。此文替代之前的 SaaS、账户和外部编码 Agent 接入路线。

## 已完成

- 网页直接进入单人 Planet，无登录注册。
- 本机 SQLite 保存 Ideas、关系、标签、Board 和 Agent 任务。
- 浏览器缓存、待写入队列及首次导入旧浏览器 Ideas。
- Idea 编辑、Sweep、延伸、时间线、标签视图、JSON 导出。
- X 插件采集、去重和正文补全。
- 本地关键词 Recall，带引用输出并保存成新 Idea。
- 本地 API、revision 冲突检测、任务状态与事件记录。

## 下一步

1. 完善本地数据管理：导入恢复、冲突处理、Board 偏好持久化。
2. 用户自配模型 Provider、API Key 和模型。
3. 基于个人 Idea 的综合和写作，支持编辑结果及来源关系回写。
4. 再验证研究、智能关联和旧 Idea 重现。

## 已移除

账户、密码、会话、注册登录、云端同步日志、营销首页、虚构社区统计、云端部署蓝图及收费设计文档。

SQLite 是本机服务的数据库，不是官方云端数据库。保留 revision 用于避免多个本地窗口静默覆盖修改，保留任务事件用于追踪 Recall 执行。

暂不做 Codex / Claude Code / MCP 集成。面向 Agent 的自动部署文档放在产品完成后的发布整理阶段。
